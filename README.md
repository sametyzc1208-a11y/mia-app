# MIA — Social Chat Starter

A React Native + Expo starter for an Android/iOS social chat app.

## Included
- Chats, Discover, Profile tabs
- Local demo chat UI and message composition
- Random-chat preview flow
- Male and female AI companion preview profiles
- Supabase starter SQL schema for profiles, friendships, conversations, messages and reports

## Run locally
1. Install Node.js LTS.
2. In this folder run `npm install`.
3. Run `npx expo start`.
4. Scan the QR code with Expo Go, or press `a` / `i` for an emulator.

## Important demo limitations
This is a runnable **frontend preview**, not a production messaging service:
- People shown in Discover and Chats are demo profiles.
- Messages are stored in app memory and reset when the app restarts.
- AI replies are sample responses, not generated by a real AI model.
- Login, live matching, push notifications, image uploads, moderation workflows and ad monetization are not connected yet.

## Connect a real backend
1. Create a Supabase project.
2. Run `supabase/schema.sql` in the Supabase SQL Editor.
3. Copy `.env.example` to `.env` and fill in the Supabase project URL and anon key.
4. Implement authenticated profile creation, conversation membership, realtime message subscriptions and report/block workflows.
5. Put AI API calls behind a server-side Edge Function. Never ship a private AI API key inside the mobile app.

## Before public launch
- Add verified age-appropriate onboarding and community rules.
- Implement block, report, moderation review and abuse-rate limits.
- Add privacy policy, terms, account deletion and data retention controls.
- Test RLS policies with separate test accounts; the included SQL is a starter and needs a security review.
- Configure app store identifiers, signing, screenshots and store compliance.
